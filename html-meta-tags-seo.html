12. Meta Tags and SEO Basics

Explains commonly used meta tags for character encoding, viewport control, description and SEO.

View this page's source (Ctrl+U) to see these meta tags in the <head>:

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Practical HTML program demonstrating meta tags">
<meta name="keywords" content="HTML, practical, meta tags, SEO">
<meta name="author" content="Shaik Abdulkalam">

These tags don't render visibly, but control encoding, mobile scaling, and what search engines display in results.
